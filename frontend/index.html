Borrowed Badge

Check whether a website, UPI/bank detail or phone number is actually attached to the entity that holds the SEBI registration someone showed you.

A badge can be real without the person wearing it being its owner. Most checks ask “is this registration number valid?”. This one asks “is this channel connected to the entity that holds it?” — a real registration number is exactly what an impersonator borrows.

This tool holds no SEBI data. SEBI's portal blocks automated lookups, so you confirm the registration on SEBI's own site, read off the official details, and paste them back below. Domain facts are looked up live from the public domain registry (RDAP).
